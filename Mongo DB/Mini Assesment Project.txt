-->Count Orders per Restaurant :

db.orders.aggregate([
{
    $group: {
        _id: "$restaurant_id",
        orderCount: { $sum: 1 }
    }
}
]);

--> Top 2 Restaurants by Average Order Amount

db.orders.aggregate([
{
    $group: {
        _id: "$restaurant_id",
        averageOrderAmount: {
            $avg: "$total_amount"
        }
    }
},
{
    $sort: {
        averageOrderAmount: -1
    }
},
{
    $limit: 2
}
]);
