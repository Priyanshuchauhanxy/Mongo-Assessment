--> Single Field Index :

- Before creating index

   db.restaurants.find({
    cuisine: "Italian"
   }).explain("executionStats");

- Create index
   db.restaurants.createIndex({
    cuisine: 1
   });

- After creating index
   db.restaurants.find({
    cuisine: "Italian"
   }).explain("executionStats");

--> Compound Index :

 - Create compound index
   db.restaurants.createIndex({
    location: 1,
    rating: 1
   });

 - Query Ahmedabad restaurants with rating > 4
   db.restaurants.find({
    location: "Ahmedabad",
    rating: { $gt: 4 }
   }).explain("executionStats");


--> Remove Cuisine Index :

 - Drop cuisine index
   db.restaurants.dropIndex({
    cuisine: 1
   });

- Check query performance again
   db.restaurants.find({
    cuisine: "Italian"
   }).explain("executionStats");


--> Text Index :

 - Create text index on name
   db.restaurants.createIndex({
    name: "text"
   });

 - Search restaurants containing "Pizza"
   db.restaurants.find({
    $text: {
        $search: "Pizza"
    }
   });
